# Just The Info
Just The Info was my attempt at summarizing news via AI. The project had a Python backend that pulled stories from [CNN Lite](lite.cnn.com) and used Gemini 2.5 Flash to summarize these stories. I then updated a pretty boring HTML page via JavaScript. The project had various flaws, the biggest being my lack of JS experience at the time. I also had to conserve Gemini usage to 10 or so daily stories. I also struggled with creating a GitHub action to auto-run the Python file. I definitely learned a lot from the project, but I never produced anything amazing.
