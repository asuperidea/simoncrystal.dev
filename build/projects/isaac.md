# Isaac The Carpentopod
Isaac The Carpentopod is a walking robot that uses 3D printed legs powered by DC moters. A special ration of leg lengths: [Giliam de Carpentier's Carpentopod Linkage](https://www.decarpentier.nl/carpentopod). Isaac's body is fully 3D printed in PLA, his brain is an **Arduinio mega** paired with an **L298N dual motor driver** that powers both of Isaac's **Gearbox DC Motors**. These rations were generated by Giliam using software that eveloved thousands of leg generations until it found an ideal linkage. Giliam was inspried by [Jansen's linkage](https://en.wikipedia.org/wiki/Jansen%27s_linkage), a similar linkage designed by kinetic sculptor Theo Jansen for his [*Strandbeest*](https://en.wikipedia.org/wiki/Theo_Jansen#The_strandbeest).
Isaac was built for the [Hackclub](https://hackclub.com/) program [Macondo](https://macondo.hackclub.com/). For previous projects, Hackclub provided me with funding and an amazing community. You can see [**Isaac on Hackclub here**](https://macondo.hackclub.com/projects/7520).
