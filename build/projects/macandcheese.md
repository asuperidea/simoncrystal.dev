# Mac And Cheese-Ropad
Mac And Cheese-Ropad is a macropad I designed for [Hack Club Blueprint](https://blueprint.hackclub.com). The macropad was designed to have 16 switches in a 4x4 layout. I used KiCad to design the PCB, Onshape for the case, and QMK for the firmware. Because I was new to macropads, I followed a Hack Club guide that helped me learn KiCad. After some design iteration I submitted my project and Hack Club sent me the PCB and parts I needed. Currently the macropad is soldered but has some hardware issues.
