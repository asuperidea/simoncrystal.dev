# Isaac The Carpentopod (Robot)
Isaac The Carpentopod is a walking robot that uses [Giliam de Carpentier's *Carpentopod* Linkage](https://www.decarpentier.nl/carpentopod). Isaac's body is fully 3D printed in PLA, his brain is an **Arduinio mega** paired with an **L298N dual motor driver** that powers both of Isaac's **Gearbox DC Motors**. Isaac was designed in [OnShape](https://cad.onshape.com/documents/fd8d649ce3643e24ce6086ff/w/2fd19f425c5ef16a61c62a1e/e/ff1b6042f026958810a4dbde?renderMode=0&uiState=6a542440be2fa235f951ae78) using the ratios Giliam de Carpentier used in his [Walking Table](https://www.decarpentier.nl/carpentopod). These rations were generated by Giliam using software that eveloved thousands of leg generations until it found an ideal linkage. Giliam was inspried by [Jansen's linkage](https://en.wikipedia.org/wiki/Jansen%27s_linkage), a similar linkage designed by kinetic sculptor Theo Jansen for his [*Strandbeest*](https://en.wikipedia.org/wiki/Theo_Jansen#The_strandbeest).
Isaac was built for the [Hackclub](https://hackclub.com/) program [Macondo](https://macondo.hackclub.com/). For previous projects, Hackclub provided me with funding and an amazing community. You can see [**Isaac on Hackclub here**](https://macondo.hackclub.com/projects/7520).
